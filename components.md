# Components Checklist

Use this checklist to record the exact parts you buy. Prices are intentionally left blank until you confirm current prices from your supplier.

| Component | Purpose | Notes / status | Price |
|---|---|---|---|
| ESP32 development board | Reads sensors and connects to Wi-Fi | Confirm exact board model | To be added |
| USB data cable | Programming and power during setup | Must support data, not charging only | To be added |
| Breadboard | Prototyping circuit | Optional if using another safe prototyping method | To be added |
| Jumper wires | Connect modules | Match the board and module pin headers | To be added |
| Soil moisture sensor | Estimates soil moisture | Capacitive type is often preferred for soil use | To be added |
| pH probe + interface module | Measures pH after calibration | Use a soil-appropriate method; many probes measure liquid samples rather than being inserted directly into soil | To be added |
| Low-voltage pump | Waters plant (future feature) | Optional; do not connect directly to GPIO | To be added |
| Pump driver or suitable relay module | Switches pump power | Must be rated for pump voltage and current | To be added |
| Separate pump power supply | Powers the pump | Match pump specifications | To be added |
| Optional display | Local readout | Choose a compatible I2C/SPI display | To be added |
| Potting/container and tubing | Holds plant and directs water | Optional | To be added |

## Before buying
- Check module operating voltage and output voltage.
- Confirm the sensor's pin labels and ESP32 pinout.
- Check whether the pH kit includes its interface board and calibration instructions.
- Keep the total budget and supplier details in your project journal.
